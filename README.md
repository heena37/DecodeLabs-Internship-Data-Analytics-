
### - PROJECT - 1 (Data Cleaning & Preparation): Overview
This project is to prepare a raw dataset for further analysis by cleaning the data. There were a number of missing values, duplicate data and inconsistencies in data types.

# Objective:
- Identify missing/null values
- Remove duplicate records
Correct Incorrect Data Formats
- Organize and create clean data for analysis.

# Tools & Technologies:
- Python, Pandas, Google Colab

 # Dataset:
Dataset was shared during Data Analytics Internship and contains transactional business-related data including:
- Customer information
- Product details
- Payment methods
- Order status
- Sales values
- Pricing information
  
# Tasks Performed:
- Loaded dataset using Pandas
- Checked dataset information
- Identified null values
- Filled missing values
- Removed duplicates
- Standardized text columns
- Saved cleaned dataset

# How to Run:

1. Open Google Colab
2. Upload dataset file
3. Execute the cells in the notebook one by one
Install required library:
pip install pandas
