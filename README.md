->Objective
- Identify missing/null values
- Remove duplicate records

Dataset provided during the DecodeLabs Data Analytics Internship.

- Checked dataset information
- Identified null values
- Filled missing values
- Removed duplicates
- Standardized text columns
- Saved cleaned dataset

->Objective
- Extract insights from data using SQL queries
- Filter and sort records
- Group data for analysis
- Perform aggregations like COUNT, SUM, and AVG

->Tools & Technologies
- Python, Pandas, PandaSQL, Google Colab, SQL

->SQL Operations Performed:

2. Upload the dataset file
